
# Release Notes - V23 Internal Beta

## Tổng quan
V23 là bản beta nội tộc đầu tiên, tập trung vào kiểm thử thực tế trước production launch.

## Nền tảng đã có
- React + Vite.
- React Flow tree.
- Static JSON / Supabase-ready mode.
- Auth + Role + Privacy.
- Admin CMS.
- Grave Map + QR.
- Internal Network.
- Career/Mentor.
- Beta Dashboard.

## Điểm mới V23
- Beta checklist.
- Feedback / Bug report form.
- Data quality metrics.
- UAT script.
- Beta feedback schema.
- Beta test run snapshot.

## Lưu ý
- Đây vẫn là bản beta, chưa nên public rộng.
- Cần test với nhóm nhỏ.
- Dữ liệu mộ phần cần tọa độ thật.
- Các patch JSON cần được admin duyệt trước khi nhập chính thức.
